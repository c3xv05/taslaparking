# Tesla Hover Parking Simulator — Neon Missions

**未來懸浮停車模擬器：駕駛、起飛、穿越光環，最後精準停車。**

使用 Three.js 製作的單人 3D 網頁遊戲。玩家必須在 90 秒內依序完成飛行檢查點，管理能量與碰撞風險，再將整輛車停入指定車格。

所有自訂 HTML、CSS、JavaScript 整合於單一 `index.html`，可部署至 GitHub Pages，不需要後端、資料庫、API Key 或 npm 建置。

> 本作為非官方虛構概念，與 Tesla 無關。懸浮並非真實 Tesla 車輛功能。
>
> 專案目前為已實作的互動原型。核心邏輯已做模擬檢查，實際 WebGL 畫面、音效、手機效能與公開部署尚未完成驗收。

## 特色

- **兩種駕駛模式**：地面加速、倒車、滑行與轉向；低空懸浮、平移與升降。
- **四個循序解鎖關卡**：啟航學院、霓虹城區、天際平台與精準車庫。
- **任務與能量管理**：依序飛越光環、使用充電區，避開路障及限高結構。
- **3D 高度碰撞**：能飛越低矮物件，也會撞到車輛、橫梁與邊界。
- **夜間城市氛圍**：霓虹、雨景、程序環境反射、懸浮粒子及車身動態。
- **三種視角**：車尾跟隨、全場俯視、可拖曳的自由鏡頭。
- **成長與自訂**：遊戲點數、五種車色、四種車底光及六項成就。
- **完整遊戲介面**：小地圖、方向導航、任務進度、HUD 與結算細項。
- **手機操作**：虛擬搖桿、多指升降按鈕與取消輸入處理。
- **本機存檔**：保留關卡、分數、星級、商品、成就及偏好。
- **程序音效**：使用 Web Audio API，不需額外音效檔。

## 開始遊玩

需要可使用 WebGL 2、ES Modules 與 import maps 的現代瀏覽器，以及載入 Three.js CDN 的網路連線。Web Audio API 不可用時，核心遊戲仍可執行。

目前沒有已驗證的公開遊玩網址。完成 Pages 部署後，可將實際網址填入儲存庫 About 的 Website 欄位。

### 本機預覽

在含有 `index.html` 的資料夾啟動一般靜態 HTTP 伺服器。例如已安裝 Python 3 時：

```bash
python -m http.server 8000
```

開啟：

```text
http://localhost:8000/
```

Python 僅用於開發預覽；部署後玩家不需要安裝。

建議使用 HTTP/HTTPS，避免直接以 `file://` 開啟產生不同瀏覽器的模組與儲存限制。

## 操作

| 按鍵 | 地面模式 | 懸浮模式 |
| --- | --- | --- |
| W / ↑ | 前進 | 向前平移 |
| S / ↓ | 減速、倒車 | 向後平移 |
| A / ← | 左轉 | 向左平移 |
| D / → | 右轉 | 向右平移 |
| Space | 起飛 | 開始降落 |
| R / F | — | 上升／下降 |
| C | 切換視角 | 切換視角 |
| P / Esc | 暫停／繼續 | 暫停／繼續 |

自由鏡頭可拖曳旋轉、使用滾輪縮放。

降落中若仍有至少 15% 能量，再按 Space 可取消降落。

手機使用左下搖桿和右下起降、升降按鈕；頂部可切換視角、音效、雨景、畫質及暫停。建議橫向。

切換分頁或頁面失焦會自動暫停。

## 怎麼完成任務

1. 選擇已解鎖關卡並開始。
2. 依序飛越目前亮起的青色光環。
3. 使用右側導航與小地圖尋找下一個目標。
4. 全部光環完成後，前往紅色目標車格。
5. 將完整車身停入格內、落地並放開控制。
6. 穩定 0.5 秒即成功。

不強制車頭朝向，但整個車身矩形必須放在車格內。

時間歸零即失敗；直接停車而未完成光環，不會成功。

### 能量與碰撞

- 起始能量 100%，至少 15% 才能起飛。
- 最高相對高度 5 m。
- 懸浮每秒消耗 12 個百分點。
- 一般落地每秒恢復 18 個百分點。
- 在青色充電區落地停穩，每秒總共恢復 42 個百分點。
- 能量耗盡會自動降落。
- 若下方有障礙物，請平移至空地。
- 每次有效碰撞扣 5 秒，接著有 1.5 秒扣時保護。
- 保護期間仍會阻擋實體碰撞。

## 關卡

| 關卡 | 光環 | 車格寬度 | 節能預算 | 挑戰 |
| --- | --- | --- | --- | --- |
| 啟航學院 | 1 | 4.6 | 60% | 起降與停車練習 |
| 霓虹城區 | 2 | 4.2 | 110% | 城市航線與回充規劃 |
| 天際平台 | 3 | 3.8 | 180% | 高架場地與較長航線 |
| 精準車庫 | 2 | 3.5 | 100% | 狹窄車格、立柱與限高 |

每關均為 90 秒，成功後解鎖下一關。

目標車格及合法停放車輛／路障配置會隨重試改變。

節能預算是整局的累計耗能門檻，不是電池容量。回充後再次飛行仍計入累計耗能，所以數值可能超過 100%。

## 分數、點數與車庫

成功分數為 0～100，權重為：

| 項目 | 配分 |
| --- | --- |
| 剩餘時間 | 60 |
| 碰撞表現 | 25 |
| 能量效率 | 15 |

能效依各關預算計算。完整公式見 [詳細規格書](docs/SPECIFICATION.md#14-計分星級與點數)。

- 80～100 分：三星。
- 55～79 分：二星。
- 0～54 分：一星。
- 失敗不給星級與本局點數。

成功獲得：

```text
80 + 本局分數
```

以下各額外獲得 40 點：

- 零碰撞。
- 累計耗能不超過關卡預算。
- 剩餘至少 31.5 秒。

首次成就各再加 40 點。

點數可解鎖霧銀、極地藍、曜石黑、日蝕金車色，以及冰青、紫電、皓白車底光。

烈焰紅車色與緋紅光效預設擁有。外觀不改變性能；沒有真實金流。

## 存檔

使用 localStorage 的 `hover-neon-v2` 鍵保存：

- 各關最佳分數與星級。
- 解鎖進度與成功次數。
- 點數。
- 已擁有及目前使用的外觀。
- 成就。
- 音效、雨景及畫質偏好。

資料只保存在目前瀏覽器與 origin，不會跨裝置同步，也不保存未完成的一局。

清除網站資料可能失去紀錄。若同一 github.io origin 部署多份遊戲，固定儲存鍵可能共用，需自行加上專案命名空間。

程式會嘗試帶入舊版 `hover-parking-v1` 的最佳分數、星級、成功次數與音效偏好。

瀏覽器禁止儲存時仍可玩，但無法保證保留紀錄。

## GitHub Pages 部署

建議儲存庫結構：

```text
tesla-hover-parking/
├── index.html
├── README.md
└── docs/
    └── SPECIFICATION.md
```

如果目前入口位於 `dist/index.html`，先取出該檔，放到 GitHub 儲存庫根目錄。

1. 建立 GitHub 儲存庫並上傳上述檔案。
2. 開啟 **Settings → Pages**。
3. Source 選擇 **Deploy from a branch**。
4. Branch 選擇 **main**，資料夾選擇 **/ (root)**。
5. 儲存，等待 GitHub Pages 完成部署。
6. 使用 Pages 設定頁顯示的實際網址開啟遊戲。

專案網址格式範例：

```text
https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/
```

上面是格式範例，不是已驗證的遊玩連結。

部署後請確認真實 CDN 載入、鍵盤／觸控、存檔重整及專案子路徑正常。

## 技術與修改

| 項目 | 技術 |
| --- | --- |
| 3D | Three.js 0.170.0、原生 Geometry／Material／Light |
| 依賴載入 | 固定版本 CDN import map |
| UI | 原生 HTML／CSS／JavaScript |
| 音效 | Web Audio API |
| 小地圖 | Canvas 2D |
| 存檔 | localStorage |
| 部署 | 靜態 HTTP/HTTPS、GitHub Pages |

`index.html` 內依職責分成十個區段。常用調整位置：

| 設定 | 用途 |
| --- | --- |
| `CFG` | 車速、加速度、轉向、能耗、回充、碰撞及停車條件 |
| `LEVELS` | 時限、車格寬度、場地高度、光環與節能預算 |
| `PAINTS` / `LIGHTS` | 外觀名稱、顏色與價格 |
| `ACH` | 成就名稱與說明；條件另見 `finish()` |
| `scoreRun()` | 計分公式 |
| `finish()` | 結算、點數、成就與進度 |

修改航線、車速、時限或能耗後，請重新驗證：

- 每關是否可完成。
- 是否可取得合理星級。
- 隨機配置是否保留通道。
- 手機畫質與操作是否仍可接受。

## 已知限制與疑難排解

### 載入失敗

確認瀏覽器支援 WebGL 2，並可存取 `cdn.jsdelivr.net`。建議以 HTTP/HTTPS 開啟。

### 操作卡頓

切換省電畫質或關閉雨景。

自動畫質依輸入裝置類型選擇，不會自動量測 FPS。

### 沒有聲音

音效預設關閉，請開啟後互動。裝置或瀏覽器限制也可能阻擋音訊。

### 降落卡在上方

下方可能有實體障礙，請移至空地。懸空不會回充。

### 停進車格仍沒成功

確認：

- 光環已全部完成。
- 完整車身在格內。
- 已落地。
- 放開控制並停穩 0.5 秒。

### 紀錄未保存

確認瀏覽器允許網站儲存，並使用相同瀏覽器及網址 origin。

### 其他限制

- 碰撞與車輛物理採簡化模型。
- 光環為空間觸發區，沒有指定穿越方向。
- 反光採程序環境反射與簡化光影，沒有光線追蹤。
- 攝影機未實作完整建築避障。
- 沒有離線快取、雲端同步、線上排行榜、防作弊或多人模式。
